# 声线练习室 · 离线复习调度台

纯前端（Vite + React + TypeScript）的发音练习与复习调度工具，全部数据只存本机：
领域数据存 `localStorage`，录音 Blob 存 IndexedDB，离线机器评分为本地模拟。**不新增任何依赖。**

## 功能规则

- **练习落库**：每次练习保存句子、机器分、错音标签、用时和录音；多次练习先攒成「批次草稿」。
- **同一句每天最多 3 次**（按句子版本计：今日已写入次数 + 本批次数合并计算）。
- **当天总用时不超过 20 分钟**（今日已写入用时 + 本批用时合并计算）。
- **整批事务**：任一规则超限，整批不写入；草稿保留、冲突逐条列出（句子、次数、原值、合并值、规则、用时），冲突随草稿持久化，刷新仍可见。
- **复习调度**：机器分 < 85 的句子自动安排次日复习；存在未完成复习（或最近一次低于 85 分）时不能标记「已掌握」；达标练习自动完成复习。
- **版本化句子**：修改句子会生成只读新版本；旧录音与旧分数永远归旧版本，旧版未完成复习自动归档，新版本需重新达标。
- **刷新一致**：复习队列、批次、版本均从同一份持久化状态派生。

## 架构（领域 / 调度 / 页面分离）

- `src/domain/` — 类型、规则常量、纯函数调度器（校验、提交、复习、版本）、种子数据；不依赖 React / DOM。
- `src/state/` — `localStorage` + IndexedDB 存储、React Store、MediaRecorder 录音 Hook。
- `src/pages/`、`src/components/` — 练习台 / 复习队列 / 批次记录三个页面与通用组件。

## 命令

```bash
npm install
npm run dev          # 本地开发
npm run build        # 类型检查 + 构建
npm run test:rules   # 领域规则冒烟测试（32 条断言，仅用项目已有的 typescript 转译）
```

麦克风不可用或被拒绝时，可使用「模拟计时练习」走完整个调度流程。
