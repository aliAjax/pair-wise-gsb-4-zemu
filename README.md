# 声线练习室 · 离线复习调度台

纯前端（Vite + React + TypeScript）的发音练习与离线复习调度工具，数据仅存浏览器 localStorage，不新增任何依赖。

## 规则

- 每次录音保存：句子（含版本）、机器分、错音标签、用时。
- **同一句每天最多 3 次；当天总用时不超过 20 分钟**。录音先进入草稿批次，整批校验通过才原子写入；任一超限则整批不写入并保留草稿，冲突逐条列出“句子 / 次数 / 原值 / 规则”。
- 机器分 **低于 85 分安排次日复习**；复习完成前不能标记已掌握（需有 ≥85 分录音且无未完成复习）。
- 修改句子文本/译文会产生**新版本**，旧录音与旧分数保留并归属旧版本；复习队列展示触发复习时的版本快照。
- 刷新后队列、批次、版本从同一份持久化状态派生，保持一致。

## 结构（领域数据 / 调度 / 页面分离）

- `src/domain/` — 类型（`types.ts`）、时间桶（`time.ts`）、确定性机器打分（`scoring.ts`）、版本模型与种子（`model.ts`）
- `src/scheduler/scheduler.ts` — 纯函数规则：限额校验、冲突明细、批次原子提交、次日复习、掌握判定
- `src/state/store.ts` — reducer 与 localStorage 持久化、选择器
- `src/ui/` + `src/App.tsx` — 页面组件与装配
